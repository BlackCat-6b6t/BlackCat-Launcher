# BlackCat Launcher 🐈‍⬛

A Minecraft launcher for Windows. Official accounts, fully separate instance management, a built-in mod store, local server hosting, and much more — all in one app.

Developed by **Stellars**, **Malware** and **Meseju**.

💬 Discord: https://discord.gg/Uu6dHVnCSA

## ✨ Features

### Accounts
- Sign in with **Microsoft/Xbox** (official) or **offline mode** with any username
- Multiple saved accounts, with automatic session refresh

### Instances
- Every install is its own **independent instance** with its own mods, worlds, configs and screenshots
- Creating a new instance automatically carries over **worlds, resource packs, configs and saved servers** from your active instance — but never the mods
- Instance editor: custom name, icon, RAM and JVM args per instance
- Duplicate, export (.zip) and import instances
- Built-in per-instance file browser with drag-and-drop
- Automatic world backups before every play session
- Installed-version cleanup with disk usage reporting
- Detects and imports instances from **other launchers**: Official Launcher, TLauncher, SKlauncher, CurseForge, Prism/MultiMC/PolyMC, ATLauncher, GDLauncher and the Modrinth App

### Mod store
- Search **mods, modpacks and resource packs** on Modrinth and CurseForge (bring your own API key)
- "Compatible only" filter against your active instance
- Pick the target instance and exact version before installing
- **Batch install**: select multiple mods and install them all at once
- Detects manually-added mods by file hash
- Detects missing dependencies (Fabric API, etc.) with one-click install
- Mod update checker with an "update all" button
- Update installed modpacks in place without losing worlds or configs

### Servers
- Saved server list with **real ping** (native Minecraft protocol): online players, MOTD and latency
- **Local server hosting (LAN)**: create and manage your own dedicated server (Vanilla or Fabric) right from the launcher — start, stop, interactive console, world backup and file browser

### Customization
- Fully customizable color themes, with presets and saved themes
- Configurable animated backgrounds
- English and Spanish, with a language switcher
- Guided first-run tour
- Export and import your whole configuration (themes, servers, preferences) to a file

### Extras
- Playtime tracking per instance
- Skins: preview and switch
- Global chat and direct messages between launcher users
- Crash report parsing with an automatic summary
- Screenshot gallery
- Discord Rich Presence
- Command palette (Ctrl+K) for quick navigation
- Automatic launcher updates
